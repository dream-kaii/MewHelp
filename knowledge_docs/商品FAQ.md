# 商品FAQ

## 常见问题一览

下表汇总了买家最常问到的问题,答案可在本页直接查询;若下表未能解决您的问题,可在对话中直接向客服提问。

| 问题 | 解答 |
|---|---|
| 能开票吗? | 支持开具电子发票。下单时在结算页填写发票抬头与税号,发货后 1 个工作日内发送到预留邮箱;需要纸质发票请在订单备注中说明。已经开票的订单如需修改抬头,请联系客服作废后重开。 |
| 是正品吗? | 全部商品均由品牌方或一级授权经销商供货,支持全国联保与专柜验货,假一赔十。收到商品后可凭订单号在品牌官网查询防伪码。 |
| 尺码怎么选? | 每个商品详情页都附有尺码对照表,建议按实际测量的胸围、腰围、肩宽对照选择;拿不准时把身高体重发给客服,由客服协助推荐。 |
| 缺货了会补货吗? | 热销款一般在 7-15 天内补货,可点击商品页的「到货提醒」,补货后系统会通过短信与站内信通知,补货当天完成支付可优先发货。 |
| 支持哪些支付方式? | 支持支付宝、微信支付、银行卡与花呗分期,单笔订单满 300 元可享 3 期免息,满 1000 元可享 6 期免息,具体以结算页展示为准。 |
| 优惠券怎么使用? | 在结算页选择可用优惠券自动抵扣,每笔订单限用一张,优惠券不找零、不折现,过期未使用自动失效且不予补发。 |
| 发货要多久? | 现货商品在支付成功后 48 小时内发出,预售商品以详情页标注的发货时间为准;大促期间订单量较大,发货可能顺延 1-2 天。 |
| 可以修改收货地址吗? | 订单未发货前可在「我的订单」中自助修改一次收货地址;已发货的订单无法修改,建议联系快递员协商转运或拒收后重新下单。 |
| 支持货到付款吗? | 部分城市支持货到付款,下单时结算页若显示该选项即可选择;货到付款订单不支持使用优惠券,需按商品原价支付。 |
| 怎么联系人工客服? | 在对话中直接提问即可,系统会先尝试自动解答;若需人工介入,回复「转人工」,客服会在工作时间 9:00-21:00 内接入。 |
| 会员积分怎么算? | 每消费 1 元累计 1 积分,积分可在下次购物时抵扣,100 积分抵 1 元;积分自获得之日起 12 个月内有效,过期清零。 |
| 可以指定快递公司吗? | 默认由系统根据收货地区智能选择快递,不支持指定;偏远地区将自动匹配可送达的快递,可能增加在途时间。 |

## 发票说明

电子发票与订单金额一致,开票内容可选商品明细或商品类别。发票抬头支持个人或企业;企业抬头需提供公司名称与纳税人识别号。已经开票的订单如需修改发票信息,请联系客服作废后重开。

## 物流与收货

下单后 48 小时内发货,预售商品以详情页标注时间为准。收货时请当面验货,发现破损可拒收并联系客服补发。
