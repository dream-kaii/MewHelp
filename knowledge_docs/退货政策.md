# 退货政策

## 退货流程

自签收之日起 7 天内,商品未使用、不影响二次销售且包装完好的,可以申请无理由退货。

申请退货的具体步骤如下:

1. 进入「我的订单」,找到对应订单,点击「申请退货」。
2. 选择退货原因,上传商品照片,提交退货申请。
3. 商家在 24 小时内审核,审核通过后按页面提示将商品寄回指定地址。
4. 商家收到商品并验收无误后,退款将在 1-3 个工作日内退回原支付渠道。

寄回商品时请保留物流单号,方便查询进度与售后跟进。

## 七天无理由退货规则

自签收起 7 天内可以无理由退货,但以下商品不支持七天无理由退货:

- 定制类商品、鲜活易腐商品;
- 已拆封的贴身用品、食品、化妆品;
- 页面明确标注「不支持七天无理由」的特价与清仓商品。

无理由退回的商品应当保持完好,配件、赠品、保修卡、发票需一并寄回,否则可能影响退款。

## 退货条件与不予退货

以下情形商家有权拒绝退货或按折价处理:

- 商品被人为损坏、进水、私自拆修;
- 超出 7 天无理由期限且非质量问题;
- 商品与随附配件、赠品不齐全。

若因质量问题退货,商家承担来回运费,买家无需支付;非质量问题的退货,寄回运费由买家自行承担。

## 退款说明

退款在商家验收通过后发起,原路退回支付宝、微信或银行卡,一般 1-3 个工作日到账,银行渠道可能延长至 7 个工作日。若订单使用了优惠券,优惠券不予退还。
